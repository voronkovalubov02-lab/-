# Світ кіно (Movie World)

Навчальний вебпроєкт з добіркою популярних фільмів різних жанрів (фентезі, сімейні, трилери, комедії). На сайті представлено ключову інформацію про стрічки, цікаві факти та вбудовані відеотрейлери.

##  Технології
* **HTML:** Семантична розмітка, структура сторінки, вбудовані `iframe` плеєри, SEO-теги.
* **CSS:** Адаптивний дизайн, стилізація блоків з фактами та трейлерами, пропорційні розміри відео.
* **JavaScript:** Підключено зовнішній скрипт `script.js`.

##  Особливості проєкту
* **SEO-оптимізація:**
  * Використання ключових слів (`keywords`) та опису (`description`).
  * Інформативні заголовки `<h1>`–`<h4>`.
  * Описові атрибути `alt` для всіх зображень.
* **Мультимедіа:**
  * Вбудовані адаптивні YouTube-трейлери з однаковими розмірами плеєрів.
* **Інформативність:**
  * Вказано жанри та дати виходу фільмів.
  * Додано цікаві факти про створення кожної кінострічки.

## Структура проєкту
* `index.html` — головна сторінка сайту.
* `styels.css` — стилі для оформлення сторінки.
* `script.js` — файл скриптів.
* `Readme.md` — опис проєкту.

## Як запустити
1. Завантажте або склонуйте репозиторій.
2. Відкрийте файл `index.html` у будь-якому веббраузері.
